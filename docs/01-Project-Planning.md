# 📋 Project Planning

## 🎯 Project Overview

This project implements a Microsoft Intune-based endpoint management environment using a Microsoft 365 tenant and three Windows 11 virtual machines hosted on VMware Workstation.

The goal is to demonstrate centralized device enrollment, configuration, security, application management, compliance, and monitoring.

## 🎯 Objectives

- 💻 Manage Windows 11 devices with Microsoft Intune
- 🔐 Apply centralized security and compliance policies
- 📦 Deploy and manage applications
- 🔄 Configure Windows Update management
- 🖥️ Implement Windows Autopilot
- 🔗 Integrate Intune with Microsoft Entra ID and Conditional Access
- 📊 Monitor device health and compliance

## 📌 Scope

The project covers:

- ⚙️ Intune configuration
- 🔐 Device enrollment
- 🪟 Windows Autopilot
- 🛠️ Device configuration
- ✅ Compliance policies
- 🔗 Conditional Access integration
- 🛡️ Endpoint security

- 🔄 Device management

## 🚫 Out of Scope

- 🍎 macOS management
- 📱 Android/iOS device management
- 🏢 Physical device deployment
- 🌐 On-premises Active Directory management

## ✅ Completion Criteria

The project will be considered complete when the three Windows 11 devices are successfully enrolled, configured, secured, compliant, and manageable through Microsoft Intune.
